# Java-log

A structured collection of Java practice programs and notes, organized by topic.

This repository documents my Java learning journey through small, runnable examples. Each topic is broken into focused subtopics so concepts can be studied and revisited easily.

2. Control Flow

4. Strings
5. OOP Basics
6. Inheritance

8. Abstraction and Interfaces
9. Exception Handling

## Run an example

Open a terminal in the folder that contains the Java file, then compile and run it:

```sh
javac FileName.java
java FileName
```

For example:

```sh
cd topics/09-exception-handling/1-try-catch
javac TryCatchDemo.java
java TryCatchDemo
```

## Requirements

- Java Development Kit (JDK)
- A code editor, such as VS Code

Verify that Java is installed:

```sh
java -version
javac -version
```
